How progress is calculated & saving your work

Only Completed lessons and Passed exams earn credit. In progress items earn no partial credit. The original workbook weights, teaching days and difficulty ranks are preserved. Rank 1 is the highest difficulty. Lesson names and planned durations come from the supplied SMART RPL, PPL and CPL syllabus PDFs. Durations are decimal hours; instrument time is included within the stated dual duration and is not added again. Missing or clipped information is flagged. The list contains 81 numbered lessons plus lessons 16.a and 48.a. Lesson 48.a has 0.5 weight points, matching the neighbouring hour-building lessons, and is included in progress and projections. Lesson 16.a uses the same weight as lesson 16. Other lettered lessons and ground briefs are excluded. Optional numbered lessons retain their existing progress treatment. Duration does not change progress weights or forecasts. The source also labels a ground brief as 44; this tracker uses PPL flight lesson 44. User-confirmed corrections supply the durations and training types for lessons 8, 16, 22, 25, 38, 48.a and 81.

Changes are saved in this browser where supported. Use Download updated tracker to create an HTML copy containing the current student data; the original downloaded file does not update itself. Export Excel backup saves a readable .xlsx workbook with embedded restore data. Import the original exported Excel file to restore the tracker; edits made in Excel do not update the embedded snapshot. Previous JSON backups can still be imported. New student / reset downloads an Excel backup before clearing student data. The downloaded file must be retained to restore that student. Files work offline without external libraries or a login. Email drafts use the details entered here; refresh the draft after changing progress or meeting details. There is no shared database or automatic sync between devices.

Print report produces a student progress summary including student details, dates, practical and theory completion, timeline comparison and the completion projection. The lesson list is excluded from this summary. This tracker is a progress summary and does not replace official training records.
